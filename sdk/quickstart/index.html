    ATGS Enterprise Core — Quickstart

    Overview

    ATGS Enterprise Core is a finite-state stochastic-process runtime implementing exact continuous-time Markov chain (CTMC) solvers. It is distributed as a commercial software platform for pilot evaluation and integration testing.

    Public integration surfaces: - C ABI — stable, pure-C shared/static library (include/atgs/atgs_core_c.h) - Python wrapper — pybind11 module layered on the C ABI (build from source) - CLI — JSON-in / JSON-out command-line tool (bin/atgs_cli)

    CLI Usage

    ./bin/atgs_cli --input <path/to/input.json> [--output <path>] [--pretty]

    Exit codes: 0 = success or structured refusal, 1 = parse/argument error, 2 = internal error

    Quick example — absorbing CTMC first-passage:

    ./bin/atgs_cli --input examples/cli/absorbing_fpt.json --pretty

    Expected result includes mean_fpt[0] = 0.25, variance_fpt[0] = 0.0625. See sample_outputs/absorbing_fpt_output.json for the full output in the SDK bundle.

    C ABI Linking

    See docs/SDK_INTEGRATION.md for complete linking instructions and the minimal C example in examples/c_minimal/.

    One-liner (gcc, Linux):

    gcc -I include/ examples/c_minimal/main.c lib/libatgs_core_c.so \
    -o my_atgs_app
LD_LIBRARY_PATH=lib ./my_atgs_app

    Input Schema

    See docs/CLI_REFERENCE.md or the formal schema in schemas/atgs_input_v1.schema.json. Key top-level keys:

    Key Type Notes
    generator_matrix n×n array OR use edges + n_states
    edges [[i,j,rate], ...] sparse edge-list format
    n_states int required with edges
    request_first_passage bool default true
    request_entropy_production bool default false
    request_transient_distribution bool default false
    time_horizon float required when transient requested
    initial_distribution float array required when transient requested

    Build from Source (Internal)

    Requires CMake 3.22+, C++20 compiler. Dependencies (Eigen, JSON, GTest) are fetched automatically during the first configure.

    # SDK build (shared lib + examples):
cmake -S . -B build_sdk -DCMAKE_BUILD_TYPE=Release -DATGS_BUILD_SHARED=ON -DATGS_BUILD_EXAMPLES=ON
cmake --build build_sdk
ctest --test-dir build_sdk

# Default developer build:
cmake -S . -B build && cmake --build build
