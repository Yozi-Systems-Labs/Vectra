    ATGS Enterprise Core — Refusal and Error Code Reference

    ATGS Enterprise Core uses structured status codes to communicate why a computation was either refused (rejected based on input properties) or errored (caller or system failure).

    Structured Refusals (100–199)

    Refusals are expected and recoverable. They indicate that the input does not meet the mathematical or logical preconditions for the requested solver.

    Code Name Meaning
    100 ATGS_STATUS_REFUSED_INVALID_GENERATOR The matrix is not a valid CTMC generator (e.g., non-square, NaNs).
    101 ATGS_STATUS_REFUSED_NEGATIVE_OFFDIAG An off-diagonal entry Q[i,j] is negative (tolerance: 1e-12).
    102 ATGS_STATUS_REFUSED_ROW_SUM A row does not sum to zero (relative tolerance: 1e-10).
    103 ATGS_STATUS_REFUSED_MISSING_INITIAL_DISTRIBUTION Transient distribution requested but initial_distribution is missing.
    104 ATGS_STATUS_REFUSED_INVALID_TIME_HORIZON time_horizon is missing, negative, or zero.
    105 ATGS_STATUS_REFUSED_NUMERICAL_INSTABILITY The solver encountered a singular or ill-conditioned system.
    106 ATGS_STATUS_REFUSED_NO_ABSORBING_STATES First-passage requested but the CTMC has no absorbing states.
    107 ATGS_STATUS_REFUSED_ALL_ABSORBING First-passage requested but all states are absorbing.
    108 ATGS_STATUS_REFUSED_INITIAL_DISTRIBUTION_SUM initial_distribution does not sum to 1.0 (tolerance: 1e-8).
    109 ATGS_STATUS_REFUSED_TRANSIENT_CONVERGENCE_FAILED Uniformization failed to converge within Poisson term limits.

    Caller and System Errors (200–299)

    Errors indicate a violation of the API contract or a failure in the environment.

    Code Name Meaning
    200 ATGS_STATUS_ERROR_NULL_POINTER A required pointer argument (e.g., ctx, q_matrix) was NULL.
    201 ATGS_STATUS_ERROR_INVALID_ARGUMENT A non-pointer argument (e.g., n_states == 0) was invalid.
    202 ATGS_STATUS_ERROR_BUFFER_TOO_SMALL A caller-provided output buffer was too small for the result.
    299 ATGS_STATUS_ERROR_INTERNAL An unhandled exception or logic error occurred inside the runtime.

    Handling Strategy

    1. Success (0): Proceed with results.
    2. Refusal (100–199): Do not proceed. Report the diagnostic message from ATGS_GetLastErrorMessage to the user or adjust the input. These are not "crashes."
    3. Error (200–299): Fix the calling code. These indicate bugs in the integration layer.
