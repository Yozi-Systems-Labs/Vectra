    ATGS Enterprise Core — SDK Integration Guide

    Integration Paths

    Path Use case
    Shared library (lib/libatgs_core_c.so) Dynamic linking — preferred for most integrations
    Static library Embedded or single-binary deployments
    CLI (bin/atgs_cli) Pipeline integration, scripting, evaluation
    Python wrapper Python consumers (requires source build via pybind11)

    All paths route through the same stable C ABI (include/atgs/atgs_core_c.h).

    C/C++ Linking — Shared Library

    Headers: include/atgs/atgs_core_c.h

    Library: lib/libatgs_core_c.so (Linux) or lib/libatgs_core_c.dylib (macOS)

    gcc / clang

    gcc -I /path/to/sdk/include \
    your_program.c \
    /path/to/sdk/lib/libatgs_core_c.so \
    -o your_program

# Run with rpath or LD_LIBRARY_PATH:
LD_LIBRARY_PATH=/path/to/sdk/lib ./your_program

    CMake (standalone consumer)

    add_executable(my_app main.c)
target_include_directories(my_app PRIVATE /path/to/sdk/include)
target_link_libraries(my_app PRIVATE /path/to/sdk/lib/libatgs_core_c.so)

    Context Lifecycle

    #include "atgs/atgs_core_c.h"

ATGS_Context* ctx = ATGS_CreateContext();
// ... perform operations ...
ATGS_FreeContext(ctx);   // always free; no automatic lifetime management

    One context per logical compute thread. Not thread-safe across threads.

    Calling Convention

    All operations take a flat, row-major double array for the generator matrix. Output arrays are pre-allocated by the caller.

    // n-state CTMC: Q is a double[n*n] in row-major order
double Q[n * n] = { ... };

// Outputs must be pre-allocated to length n
double mean[n], variance[n];

ATGS_StatusCode status =
    ATGS_SolveFirstPassage(ctx, Q, n, mean, variance, n);

    Status Code Categories

    Range Meaning
    0 Success
    100–109 Structured refusal (computation rejected, not a crash)
    200–299 Caller error (null pointer, bad argument, buffer too small)

    Always check the return value. Structured refusals (100–109) are expected and recoverable — they carry diagnostic information via ATGS_GetLastErrorMessage.

    Error Retrieval

    if (status != ATGS_STATUS_SUCCESS) {
    char msg[512];
    ATGS_GetLastErrorMessage(ctx, msg, sizeof(msg));
    fprintf(stderr, "status %d: %s\n", (int)status, msg);
}

    Timing

    ATGS_TimingSummary timing;
ATGS_GetLastTimingSummary(ctx, &timing);
printf("total: %.2f ms\n", timing.total_ms);
