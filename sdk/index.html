    Vectra SDK

    The Vectra SDK provides the libraries, headers, and tools required to embed the Vectra™ runtime into your own diagnostic and simulation applications.

    Integration Surfaces

    The SDK is built to provide maximum stability while maintaining the performance of the underlying ATGS Enterprise Core.

    ATGS C ABI (Primary)

    The technical foundation of the SDK is the stable ATGS C ABI. This pure-C boundary ensures that the Vectra runtime can be integrated into virtually any language or environment with binary stability.

    Python Wrapper

    A high-level binding built on top of the ATGS C ABI, providing a seamless experience for Python-based diagnostic and simulation pipelines.

    Vectra CLI

    A JSON-in / JSON-out command-line tool suitable for rapid model prototyping and automated pipeline integration.
